TUTORIAL WORLD LOGIC

Spawn. Learn. Wander. Discover.

The world begins at one readable central landmark, then lets you branch outward into increasingly specialized areas. Each zone will eventually contain its own interactive demonstrations, project evidence, terminals, hidden details, and links into deeper pages.

01 // SPAWN

Orientation Plaza

Learn what Cyber Career OS is, how the world is organized, and where each path leads.

02 // BUILD

Career Base

Profile, skills, applications, job targets, approvals, and your working career state.

03 // TRAIN

Cyber Range

Labs, SIEM telemetry, investigations, controlled attack practice, and mentor-guided progression.

04 // PROVE

Evidence Vault

Turn the things you build and fix into reviewable proof instead of just claims on a résumé.

VISUAL DIRECTION

Voxel nostalgia + cyber infrastructure.

The Minecraft-like feeling comes from scale, construction, readable paths, block terrain, exploration, and guided discovery. The identity comes from Cyber Career OS: luminous data paths, infrastructure towers, terminals, status systems, lab architecture, and an original color/material language.
